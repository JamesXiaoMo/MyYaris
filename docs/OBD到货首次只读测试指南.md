# 2022 款日本 Yaris Z 混动 OBD 模块（Veepeak BLE+）到货首次只读测试指南

> **适用场景**：收到 Amazon 日本商品（ASIN: `B07VP1NHHX`，Veepeak OBDCheck BLE+）后的首次实车只读验证  
> **测试对象**：2022 款日本本土版丰田 Yaris（ヤリス）Z 混动（1.5L HYBRID / M15A-FXE）  
> **推荐软件**：**Car Scanner ELM OBD2**（官方免费基础版即可，**切勿提前购买 Pro 付费版**）  
> **核心原则**：**只读遥测、绝不写 ECU、绝不清除故障码（No Mode 04）、驻车安全第一**

---

## 一、测试前核心认知与避坑提示

1. **软件费用澄清**：
   - App Store (iOS) 与 Google Play / APK (Android) 上的 **Car Scanner ELM OBD2** 免费版已完整开放：适配器连接握手、实时传感器数据流（Live Data）、仪表盘读取、以及标准故障码（DTC）只读扫描。
   - **本次验证 100% 使用免费版即可，无需付费升级 Pro**。
2. **两阶段排查策略（iPhone 先行作为基准）**：
   - **第一轮（基准组）**：使用 **iPhone** 通过 BLE（低功耗蓝牙）直连测试。iPhone 的 BLE 协议栈规范统一，能迅速排查“硬件是否完好、车辆总线是否通畅”。
   - **第二轮（对照组）**：确认 iPhone 成功读出数据后，再使用 **Ottocast P3 Pro 车机盒子** 验证。若 iPhone 成功而车机失败，即可精准定位为车机定制系统蓝牙协议栈限制，**车机与车辆绝不会损坏**。
3. **BLE 适配器独占性（关键避坑）**：
   - Veepeak BLE+ 属于点对点无线连接，**同一时刻只允许一个客户端设备连接**！
   - 进行车机测试前，**必须先在 iPhone 上点击断开连接并完全退出 App（或暂时关闭 iPhone 蓝牙）**，否则车机绝对无法搜到或连上设备。
4. **MyYaris 车机与手机 App 现状提示**：
   - 当前仓库内的 `MyYaris`（Flutter 车机端与 iOS 端）**目前尚未开发 OBD 采集模块**。
   - **请切勿在 MyYaris App 界面内寻找任何 OBD 连接按钮或菜单**，本次验证完全使用成熟独立的第三方工具 `Car Scanner` 完成。
5. **读数认知防误判（混动特殊性）**：
   - **转速为 0 不是故障**：混动车在 READY 驻车工况下，若动力电池电量充足且无需暖机，发动机将自动熄火处于纯电待机状态，**此时转速显示 `0 rpm`、MAF 显示 `0 g/s`、发动机负荷显示 `0%` 均属完全正常的物理现象**。
   - **车速为 0**：车辆静止水平驻车，车速稳定显示 `0 km/h`。

## 二、安全防护规程（驻车安全第一）

- **场地要求**：请将车辆停放在**开阔平坦、通风良好**的户外车位或露天停车场。
- **严禁封闭怠速**：**切勿在门窗紧闭的密闭车库内长时间开启 READY 状态**（虽然处于待机，但当动力电池电量下降时发动机可能随时自动点火启动，密闭环境存在一氧化碳废气积聚风险）。
- **挡位与驻车制动**：挂入 **P 挡（驻车挡）**，确保**电子手刹（EPB）已拉起拉紧**。
- **全程严禁移动车辆**：本次测试耗时约 **10 ~ 15 分钟**，全程保持静止驻车，**严禁在行车过程中低头查看手机或操作屏幕**。

## 三、第一轮：iPhone 端基准只读测试（单步操作教程）

### 第 1 步：车辆断电下插接适配器
1. 踩下刹车前，确认车辆处于完全关闭断电状态（仪表盘全黑，POWER 按键灯熄灭）。
2. 在方向盘左下方、驾驶员膝部护板内侧下方，摸到 16 针白色梯形 OBD 诊断接口（DLC3）。
3. 取出 Veepeak OBDCheck BLE+，对准梯形方向，垂直平稳用力插入接口底部。
4. **观察指示灯**：适配器外壳上的**红色 POWER 指示灯亮起**，表明车辆 Pin 16 常电供电正常。

### 第 2 步：车辆进入 READY 就绪状态
1. 踩住刹车踏板，轻按一次车辆 **POWER** 启动按钮。
2. 观察仪表盘中央，确认亮起绿色 **READY** 字符（表明行车电脑全面唤醒，12V DC-DC 转换系统开始工作）。

### 第 3 步：iPhone 蓝牙设置（切勿系统配对）
1. 打开 iPhone 的「设置」$\to$「蓝牙」，确保蓝牙开关处于**开启**状态。
2. **重要警告**：**切勿在 iOS 系统蓝牙列表里点击 "VEEPEAK" 进行配对**！Veepeak 为 BLE 设备，系统层点击配对会报错或无法连接，必须由 App 内部直接拉起。

### 第 4 步：配置 Car Scanner 连接参数
1. 在 iPhone 上启动 **Car Scanner ELM OBD2** App。
2. 点击首页右上角或底部的 **「设置（齿轮图标）」**：
   - 点击 **「适配器 OBDII」 (Adapter OBDII)**：
     - **连接类型 (Connection type)**：选择 **`Bluetooth LE (4.0)`**（切勿选 Wi-Fi 或标准 Bluetooth）。
     - **设备名称 (Device name)**：点击后稍等 2~3 秒，在扫描出的设备列表中点击选择 **`VEEPEAK`**（或类似 `OBDCheck BLE`）。
3. 返回设置页，点击 **「车辆和连接配置」 (Vehicle options / Connection profile)**：
   - **基准测试首选**：先选择 **`OBD-II / EOBD`**（通用标准 OBD-II / EOBD CAN 模式）。  
     *(说明：先用通用标准模式验证底层物理与芯片通信，不引入第三方专有配置的干扰)*。

### 第 5 步：发起连接与握手识别
1. 返回 Car Scanner 首页，点击正中间巨大的 **「连接」 (Connect)** 按钮。
2. 观察屏幕顶部的连接时序状态：
   - 尝试连接适配器 $\to$ 适配器连接成功 (OK)
   - 读取协议 $\to$ 发动机 ECU 识别成功 (OK)
3. **成功标志**：
   - 顶部状态条变为**鲜艳的绿色**，文字显示 **「已连接」 (Connected)**。
   - 此时在「数据记录/关于」中可看到识别出的协议通常为 **`ISO 15765-4 (CAN 11/500)`**，适配器识别为 **`ELM327 v2.2`**。

## 四、核心数据采样与状态记录清单

在绿色连接状态下，返回首页，点击 **「实时数据」 (Live Data)**，逐项观察并记录以下参数：

### 4.1 优先可读基础参数核验表（标准 SAE Mode 01）

| 参数名称（App 内显示） | 驻车基准预期值 | 读数含义与状态解释 |
| :--- | :---: | :--- |
| **Engine Coolant Temp (水温)** | `20°C ~ 85°C` | **能读**。水温随发动机是否热机而异，数值应稳定且符合常理。 |
| **Vehicle Speed (车速)** | `0 km/h` | **能读**。驻车静止时严格显示为 0。 |
| **Engine RPM (发动机转速)** | `0 rpm` 或 `~1100 rpm` | **能读 / 纯电停机**。若发动机熄火显示 0 属正常；轻踩油门点火后跳至 1000~1300 rpm。 |
| **Intake Air Temp (进气温度)** | 接近车外环境温度 | **能读**。进气歧管温度传感器读数。 |
| **Calculated Engine Load (负荷)** | `0%`（停机）或 `15~30%`（点火）| **能读**。反映发动机工作负荷。 |
| **Mass Air Flow (MAF 进气量)** | `0 g/s`（停机）或 `1.5~3.5 g/s`| **能读**。热线式传感器实时空气流量。 |
| **Control Module Voltage (供电电压)**| `13.8V ~ 14.5V` | **能读**。此为 ECU 内部供电电压，READY 状态下由 DC-DC 升压稳压供电。 |
| **Engine Fuel Rate (燃油流速)** | `0 L/h` 或不支持 | **条件支持**。若显示数值表明实车支持 PID 0x5E；若显示未激活则走算法估算。 |

### 4.2 三种显示状态的标准区分
1. **「能读」**：有随物理状态合理波动的数值（如水温 65°C、电压 14.2V）。
2. **「仅显示 0」**：混动驻车熄火时的特定参数（如转速 0 rpm、进气量 0 g/s、车速 0 km/h），**属于物理状态正确，绝非读取失败**。
3. **「NO DATA / 不支持」**：显示红字、N/A 或破折号，表明 2022 Yaris 发动机 ECM 未向该通用 PID 提供数据接口。

### 4.3 故障码只读扫描（严格只读）
1. 返回首页，点击 **「故障诊断码」 (DTC / Trouble Codes)**。
2. 点击下方的 **「读取」 (Read)** 按钮。
3. 预期结果：显示 **`未发现故障码` (No trouble codes found)** 或返回特定代码。
4. **安全红线**：**切勿点击「清除」 (Clear / Reset DTCs) 按钮**！清除故障码会强制重置车辆排放就绪监控（Readiness Monitors）。

## 五、进阶选做：切换丰田混动专有扩展 Profile（可选）

完成上述通用基础数据测试后，若仍有富余时间，可尝试切换专有混动 Profile：

1. 在 Car Scanner 首页点击 **「断开连接」 (Disconnect)**。
2. 进入「设置」$\to$「车辆和连接配置」 (Connection profile) $\to$「Toyota」：
   - 查找是否有包含 **`Toyota / Lexus OBD-II / EOBD ~2016 – n.d. CAN + extra sensors`** 或 **`Toyota Hybrid`** 的配置项。
   - *(注：若列表中没有针对 2020+ Yaris 的专用选项，切勿随意尝试其他车系代码，保持该 2016+ 通用扩展配置即可)*。
3. 重新点击 **「连接」**。
4. 进入「实时数据」，在传感器选择中搜索：
   - **`Hybrid Battery SOC (%)`**（高压主电池电量百分比，通常在 40%~75% 之间）
   - **`Hybrid Battery Voltage`**（高压主电池总压）
   - **`Hybrid Battery Current`**（充放电电流，静止待机通常为 -1A ~ -3A 微弱放电）
   - **`Hybrid Battery Temp`**（电池包温度）
5. **判定准则**：
   - 若能正常读出且数值合理，记录该项为支持。
   - **若显示 NO DATA、数值异常固定、或报错，立即停止测试**，表明该 Profile 尚未适配 2022 款 M15A-FXE 混动协议，**绝不进行深挖或手动发送未经验证的私有指令**。

## 六、第二轮：Ottocast P3 Pro 车机盒子验证（对照组测试）

> **前置硬性条件**：**必须先彻底断开 iPhone 连接！**

1. **断开 iPhone**：在 iPhone Car Scanner 内点击「断开连接」，并在后台完全划掉杀掉 App（或在 iPhone 快捷控制中心临时关闭蓝牙 5 分钟）。
2. **在 Ottocast 车机上测试**：
   - 打开 Ottocast 车机盒子中安装的 Car Scanner。
   - 设置中配置适配器为蓝牙连接（根据车机实际选项选择 Bluetooth 或 Bluetooth LE）。
   - 选择设备 `VEEPEAK`，点击连接。
3. **结果判定分析**：
   - **若车机顺利变成绿色「已连接」并读出数据**：证明 Ottocast P3 Pro 的蓝牙固件对通用 OBD 串口/BLE 外设完全通畅。
   - **若车机搜不到设备、提示配对失败或超时**：在 iPhone 已验证成功的对照前提下，**完全证实问题出在后装车机定制蓝牙协议栈对非音频外设的拦截**。车辆本身与 Veepeak 适配器均完好无损，后续车机接入方案可根据此结论针对性技术攻关。
