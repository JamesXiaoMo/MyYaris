# 公开前隐私处理说明

公开文件中的后端域名、IP和用户路径均为示例。历史验证记录中的连接地址经过脱敏，不应直接用于连接实际设备。

## 本地配置

真实服务地址、设备连接地址、认证凭据与个人签名材料应仅存于被忽略的本地配置、系统凭据存储或客户端设置，不提交Git。客户端必须保留HTTPS证书和主机名验证。

## 截图与验证证据

实际账号、地图、音乐和设备截图不随公开源码发布；原图保留在忽略的本地私有目录。文档描述的验证阶段仍需区分单元测试、生产接口、真机操作和用户实际体验。

## 历史处理

只修改最新文件不能移除历史中的个人资料。历史清理在独立副本执行，保留本机备份，更新GitHub之前需要核对远端是否出现新提交。历史重写后，协作者应重新克隆或按新的提交基线迁移工作，避免把旧历史重新推回。

## 后续提交

提交前检查个人域名、私网IP、绝对用户路径、密码、Cookie、Token、签名、数据库和运行日志。截图须使用演示账号与演示地点，不能只依赖自动秘密扫描。
